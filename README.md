# Sito Web Ufficiale - Edile 360

Benvenuto nel progetto del sito web per l'impresa **Edile 360**. Il sito è stato sviluppato con tecnologie web moderne (HTML5, CSS3, JavaScript ES6), veloce, reattivo (mobile-friendly), con grafica accattivante e predisposto sia per l'apertura in locale che per la messa online immediata su qualsiasi hosting o dominio.

---


---

## 🚀 Come Visualizzare il Sito in Locale

Non è necessario installare alcun programma complesso o database:
1. Apri la cartella del progetto (`Sito Web Edile 360`).
2. Fai **doppio clic** sul file `index.html`.
3. Il sito si aprirà automaticamente nel tuo browser preferito (Chrome, Edge, Safari, Firefox).

## ✏️ Come Personalizzare i Tuoi Dati

Tutti i recapiti e le informazioni possono essere aggiornati semplicemente modificando il file `index.html`:

1. **Numero di Telefono**:
   - Cerca nel file `+39 06 9876 5432` e sostituiscilo con il tuo numero aziendale.
   - Assicurati di aggiornare anche il link `href="tel:+39..."`.

2. **Numero WhatsApp**:
   - Cerca il link `https://wa.me/39...` e inserisci il tuo numero di cellulare senza il `+` (es. `https://wa.me/393401234567`).

3. **Email Aziendale**:
   - Cerca `info@edile360.it` e sostituiscila con la tua casella email (es. `info@tuodominio.it`).

4. **Sede / Indirizzo & P.IVA**:
   - Trovi i dati nella sezione contatti e nel footer in fondo alla pagina (`P.IVA: 01234567890`).

## 🌐 Come Mettere il Sito Online (Dopo l'acquisto del Dominio)

Una volta acquistato il dominio (ad es. `www.edile360.it`) e il relativo spazio hosting, hai diverse modalità semplici per metterlo online:

### Opzione A: Hosting Tradizionale con cPanel / FTP (Aruba, Register.it, SiteGround, Serverplan, Hostinger)
1. Accedi al pannello di controllo del tuo hosting o usa un programma FTP gratuito come [FileZilla](https://filezilla-project.org/).
2. Carica tutti i file della cartella (`index.html`, la cartella `css/` e la cartella `js/`) all'interno della cartella pubblica del server (solitamente denominata `public_html`, `htdocs` o `www`).
3. Il tuo sito sarà immediatamente visibile online digitando il tuo dominio!

### Opzione B: Piattaforme Moderne e Gratuite (Netlify / Vercel / GitHub Pages)
- Puoi trascinare l'intera cartella su **Netlify** (con la funzione *Drag & Drop*) per avere il sito online in 5 secondi con certificato SSL HTTPS gratuito, collegando poi il tuo dominio personalizzato nelle impostazioni DNS.
